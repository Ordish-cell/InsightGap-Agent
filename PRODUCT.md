# Product

## Register

product

## Users
Operators, researchers, builders, and solo founders who use information gaps as inputs for research, artifacts, memory, and reusable workflows.

## Product Purpose
This product turns high-value FeedCards into Deep Research, Artifacts, Memory, Skills, Approvals, and MCP audit trails. Success means a user can discover an opportunity, validate it, produce a durable output, and make the system smarter for the next task.

## Brand Personality
Focused, exacting, calm. The interface should feel like a workbench for serious research, not a marketing site or a chat toy.

## Anti-references
Avoid generic SaaS landing-page visuals, oversized hero sections, decorative gradients, fake automation success states, and any copy implying real external writes when the backend only creates drafts or plans.

## Design Principles
- Surface the information gap first: why it matters, why it fits the user, what evidence supports it.
- Make execution traceable: every Agent run, MCP call, approval, artifact, memory, and skill should be inspectable.
- Keep the workflow dense but legible: compact panels, consistent controls, clear empty and error states.
- Never overclaim external action: drafts, plans, approval gates, and blocked states must be explicit.
- Prefer familiar product affordances over visual novelty.

## Accessibility & Inclusion
Target WCAG AA contrast for core text and controls. Support keyboard navigation, visible focus states, reduced motion, and explicit error states.
