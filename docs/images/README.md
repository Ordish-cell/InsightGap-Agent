# README 图片目录

这个目录用于存放 GitHub README 和项目文档中的图片。

建议命名：

- `hero.png`：项目首页或聊天主界面截图。
- `architecture.png`：系统架构图。
- `runtime-flow.png`：LangGraph Runtime 流程图。
- `approval-flow.png`：L3 工具审批流程图。
- `rag-flow.png`：RAG 文档检索链路图。
- `tool-calls.png`：MCP ToolCall 审计页面截图。
- `memory.png`：Memory / GSSC 页面截图。

截图前请确认不要暴露：

- API Key、Token、SMTP 密码、数据库密码。
- 真实用户邮箱、手机号、姓名。
- 业务敏感文档内容。
- 未脱敏的上传文件或 agent 输出。
